# Portfolio screenshots

Capture screenshots locally using **fabricated demo data only**. Never use real
personal tasks, names, or appointments in committed images.

## Suggested demo content

| Screen | Route | Example content |
|--------|-------|-----------------|
| Today | `/today` | "Water demo plants", "Review demo notes" |
| Week | `/week` | Thursday routine, weekly target "Demo walks" |
| Schedule | `/schedule` | "Dentist demo" all-day Oct 4 |
| Maintenance | `/maintenance` | Dentist, Physical, Oil change demo rows |

## Capture steps

1. Start backend and frontend (see [development-setup.md](../development-setup.md)).
2. Create the demo items above through the UI.
3. Screenshot at 1280×800 or similar.
4. Save to `docs/portfolio/images/` (gitignored until you choose to commit
   sanitized captures).
