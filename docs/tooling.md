# Tooling

Planforge uses local pre-commit hooks and GitHub Actions for quality and
security checks.

## Pre-commit hooks

Configuration: [`.pre-commit-config.yaml`](../.pre-commit-config.yaml)

See hook table in the previous revision — trailing whitespace, JSON/YAML/TOML
validation, gitleaks, and private-key detection.

```powershell
py -m pre_commit install
py -m pre_commit run --all-files
```

## GitHub Actions CI

Workflow: [`.github/workflows/ci.yml`](../.github/workflows/ci.yml)

| Check | Local command | CI job |
|-------|---------------|--------|
| Backend format | `ruff format --check .` | `backend / format` |
| Backend lint | `ruff check .` | `backend / lint` |
| Backend types | `mypy planforge` | `backend / typecheck` |
| Backend tests + coverage | `pytest` | `backend / test` |
| Backend dependency audit | `pip-audit` | `backend / audit` |
| Frontend format | `npm run format:check` | `frontend / format` |
| Frontend lint | `npm run lint` | `frontend / lint` |
| Frontend types | `npm run typecheck` | `frontend / typecheck` |
| Frontend tests + coverage | `npm run test:coverage` | `frontend / test` |
| Frontend build | `npm run build` | `frontend / build` |
| Frontend dependency audit | `npm audit --audit-level=high` | `frontend / audit` |
| OpenAPI schema drift | export + typegen | `frontend / openapi` |

## Python dependency lock

- Source of truth: `backend/pyproject.toml`
- Lock file: `backend/requirements.lock` (generated by `pip-compile`)
- Regenerate: `.\scripts\lock-python-deps.ps1`

Install reproducibly:

```powershell
cd backend
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
```

## Dependency audit

```powershell
# Backend
cd backend
.\.venv\Scripts\pip-audit.exe

# Frontend
cd frontend
npm audit --audit-level=high
```

Review Dependabot PRs manually; never auto-merge security-sensitive upgrades.

## OpenAPI types

1. `backend/scripts/export_openapi.py` → `frontend/openapi/openapi.json`
2. `npm run generate:api-types` → `frontend/src/api/schema.d.ts`
3. API client: `frontend/src/api/client.ts`

## Dependabot

Weekly checks for Python, npm, and GitHub Actions — see
[`.github/dependabot.yml`](../.github/dependabot.yml).
